# vsftpd 2.3.4 Backdoor Vulnerability

📌 Overview

This project demonstrates the exploitation of a backdoor vulnerability in vsftpd 2.3.4, which allows unauthorized command execution and system compromise.

🎯 Objective

To identify and exploit the vulnerable FTP service and understand its security impact.

🛠️ Key Steps

1. Scanned target for open ports
2. Identified FTP service (vsftpd 2.3.4)
3. Exploited backdoor vulnerability
4. Gained unauthorized access
   
🚨 Impact

1. Remote command execution without authentication
2. Full system compromise
3. Risk of data exposure and misuse
